# 乌坦城画景与交游手札

本轮围绕正文显示、地图与人员页面调整；沿用现有脚本、地图桥接与存档机制。

## 正文

`TavernCore.proseText` 在显示时解码一层合法 Unicode 转义，消除“目光（目光）”这类完全相同的中文重复括注；“哐哐哐（笑）了一声”这类明确注明笑意的重复拟声括注显示为“笑了一声”。代码示例、不同内容的括注、原始模型回复和历史请求内容保留。运行时格式要求增加自然中文、不用同音替换、不输出纠错式括注的约束。

模型已经写出的错词、不同内容的括注（如“译语（语气）”）和未明确标注含义的不合理拟声词不做猜测性改写；这些仍属于原始生成质量问题。未发送付费 LLM 请求验证下一轮文字质量。

## 地图

- 最小缩放铺满画框，缩放范围 1–5；平移边界跟随实际图像尺寸，不再把整幅地图拖出画框。画框与底图比例不同时会裁切部分边缘，可以拖动查看。
- 乌坦城本地点移至 (42,75)，城门驿道移至 (57,73)，圆点与名称一起分开，取消远距离指示线；道路和 Tiled 锚点同步调整。旧存档已保存的角色 pose 坐标保留，不自动搬动角色或扣资源。
- 四个形象按贴图可见高度校准，小医仙额外缩小 10%；徒步、骑乘、化翼共用校准，Pixi 与轻量 DOM 渲染一致。骑乘和飞行保留完整坐骑、翅膀所需空间。
- 体力、金币与补给分开显示，提供行旅消耗说明，具体行动仍以原规则报价与结算。
- “寻访人物”展开本地区已知人物位置；“下一处风景”优先推荐未到访地点，只预览目的地，不自动旅行或结算。
- 人物交谈卡移到侧栏，避开地图与角色。窄屏下地图、地点与行动纵向排列。

## 九处画景

地点 ID、地图详情与驻地当前地点通过 `PlaceScenes` 共享：乌坦城、萧家宅邸、坊市长街、临街客栈、拍卖场外、药材铺、佣兵告示处、城门驿道、乌坦清居。

前八处采用单独的内置 image_gen 调用生成；新增乌坦清居复用既有庭院画景，转换为独立 WebP，不更改画面内容。九处均为 1200×800 WebP 按需加载，每张 222238–276748 字节，共 2261086 字节。游戏使用 `assets/images/places/*-v1.webp`；生成原图保存在 `output/wutan-scenes-originals/*-v1.png`，提示词与文件清单见 `wutan-scenes-source.json`。

驻地优先匹配当前叙事中的具体地点；不会因为只预览了另一个目的地而换地点，也不把药材铺、萧家宅邸等画景当成玩家获得的居住权。未匹配的私人住所继续使用既有居所画景。

## 交游手札

新版人员页收录当前人生的正文关系、地图中实际交谈后有信任记录的人，以及玩家手动记下的人。支持搜索、分组筛选、标记牵挂、手札备注和拟定相逢草稿。原著索引单独折叠，不会自动成为熟人。

备注保存于 `player.personnelNotebook = {version:1, entries:[...]}`，不覆盖原关系、境界、好感、物品或剧情。沿用 Dexie 事务，成功后更新运行中玩家状态及本地备份；失败或当前人生变化时不替换玩家。与地图及驻地保存互斥。拟定相逢只写草稿，不自动调用模型。
