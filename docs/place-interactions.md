# 按画景配置交互

八处公共地点分别使用四个独立交互点，配置在 `assets/js/place-interactions.js`。坐标按各自画景的百分比设置，与地图寻路坐标独立；交互内容不再套用乌坦清居的设施。

| 地点 | 四个交互入口 |
| --- | --- |
| 乌坦城 | 向守城人问路、听商队谈见闻、观察城门布防、沿河辨认方位 |
| 萧家宅邸 | 向门房递问候、远观演武坪、廊外候见、请教来访礼数 |
| 坊市长街 | 药草摊问价、石桥口听闻、货架前比价、沿街寻差事 |
| 临街客栈 | 门前问房价、茶桌边听闲谈、问寄马寄物、询问客房规矩 |
| 拍卖场外 | 问入场资格、石阶前看公告、与商客聊行情、询问鉴物手续 |
| 药材铺 | 竹匾辨药、药柜前询货、秤盘旁问规矩、辨看灵草 |
| 佣兵告示处 | 查看委托榜、请教出城风险、行囊旁核准备、询问结伴条件 |
| 城门驿道 | 向车棚问车次、饮马处问补水、问商队去向、眺望下一程 |

乌坦清居继续使用休息、静修、备药、研习四项院内交互，已有设施、产权、记录与保存方式保留。其他既有区域的居所流程也保留。

每个交互点有独立标题、说明、条件、默认预留时长与行动意图。可以点击画面中的物件，也可以使用画面下方的文字按钮。窄屏使用编号标记与对应的大字按钮，避免多组说明相互遮挡；文字按钮紧跟图片，随后才是行动面板。公共场景不再显示通用的“炼药设施待核实”等条件或把整个地点作为可登记的新房产；已有的居所档案和待确认提案仍可查看。

选择交互只切换面板，拟定行动只写入聊天草稿。不会发起模型请求、交易、接取委托、消耗资源、改变实力、推进时间或更改地图位置。已有草稿会保留；地点变化或与当前场景不符的动作会被拒绝。真正的变化仍由现有正文和游戏规则处理。

## 亮度

旧样式 `.res-scene.night .res-scene-art` 使用 `brightness(.7) saturate(.7)`。真实页面检查确认这层滤镜已触发，尽管画面上显示的正文时间仍为早晨。现已删除该滤镜，并保证图片与承载层的计算样式为 `filter: none`、图片不透明度为 1；标签使用自己的深色底板，不压暗整张图。此轮没有修改任何画景文件。
