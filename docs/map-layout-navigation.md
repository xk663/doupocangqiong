# 地图全景与导航修复

全景缩放按图片宽、高与可用画布的较小比例计算，四边均保留。图片保持原比例，容器比例不同时允许两侧或上下留底色；放大后仍可拖动查看，缩小以完整全景为下限。

地图右侧栏在桌面宽度下收为 300px。地图标题置于顶部，缩放、定位、休整按钮并入外置导航条，说明置于图片下方，减少遮挡。

地图在隐藏子页面初始化时可能暂时没有尺寸。此时不计算相机变换，避免未定义的宽高将平移坐标变成 NaN。显示后重算尺寸；提交场景、尺寸变化及恢复显示时主动绘制首帧，不依赖点击全景。

旧的键盘检测在任意输入框获得焦点时启用键盘模式，CSS 又将侧栏限制为 44px。这会在桌面聊天、设置等页面造成导航消失。现在仅在支持触控、文本编辑器获得焦点、视口确实明显缩小且没有双指缩放时启用。侧栏的键盘压缩规则也限制在触屏横屏布局内。

页面切换先校验目标，保持一个激活页面，重复点击当前页面不重新隐藏再显示。主内容区与侧栏保持独立边界；子页面的切换动画只改变透明度。

回归检查见 `world-camera.test.cjs`、`world-avatar-races.test.cjs`、`responsive-keyboard.test.cjs` 和 `game-navigation.test.cjs`。浏览器使用现有前端及隔离练习页检查；不发送聊天请求或执行地图资源结算。
