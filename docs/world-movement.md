# Q版角色与动态地图移动

## 操作

男性使用萧炎地图形象，女性使用薰儿地图形象；其余现有性别值沿用萧炎形象。只改变地图外观，不覆盖玩家姓名、身份、关系或聊天角色卡。独立演示页顶部提供形象切换，主游戏读取当前角色的性别。

区域图中点击街巷或小径，角色沿道路寻路并播放四向迈步动画。点击人物、地点或目录条目会直接开始走近，省去先选点再确认的步骤；到附近后浮出人物的打听/自由交谈入口。WASD、方向键支持步行，拖动仍控制地图平移，滚轮和双指仍缩放。放大地图后启用「跟随」可让镜头跟随行走角色。「定位自己」聚焦实际角色位置。

「停步」或Esc会停在当前路段并保存中途位置、时间和精力；跨区域的长途旅行中断则取消本次未结算的长途行旅。地图隐藏时自动停步，切换到后台标签时暂停动画时间，恢复后继续。再次点击会更新下一处目的地，当前一段抵达后继续，不创建多个同时结算的行走任务。

地图工具栏始终提供原地休整，防止在两个地点之间精力耗尽后无处休息。只有实际靠近舒适地点才按城镇休整收费，否则按露营休整处理。人物的交谈、交易和委托由实际距离控制，不再因身处城镇总节点而全城可交互。

## 素材

`avatar-xiaoyan-sheet.png` 与 `avatar-xuner-sheet.png` 为1536×1024透明PNG，每张4列3行。四列依次南、东、北、西，三行为站立、左脚迈步、右脚迈步。PixiJS按矩形帧采样；轻量模式用同一图集的CSS背景帧，不再退化为圆点。图集由原生imagegen生成后再次通过原生imagegen去除背景，原始生成结果保留在生成目录；项目使用最终副本，没有引入额外抠图服务。提示词与图集信息记入 `world-map-art.json`。

代码播放 `[站立,左脚,站立,右脚]` 循环并按路径切换朝向。角色投影、目标标记、路径线和行走进度独立于底图绘制。图片中的装饰人物仍属于背景，6名可交互地方人物另有互动标记。

## 规则与持久化

新增 `world-navigation.js`，包含道路中心线、通行吸附、道路图寻路、路径采样、朝向及形象映射。三个区域采用手工设置的通行道路与地标连接，点击距道路较近的位置会吸附到路面，远离道路的地点拒绝通行。这是玩法道路，不是对插画逐像素识别出的建筑/河流碰撞网格；以后精修底图时仍须同步调整道路。

原有版本1探索存档增加可选字段 `pose:{sceneId,x,y,direction}`。旧存档自动从已保存地点获得初始位置，原有足迹、委托和物品保留。坐标会检查场景、范围及通行性，不能用不合法坐标跳到另一地区。

本地 `walk` 行动由纯规则重新计算路径、游戏分钟和精力，忽略调用方传入的任意费用。`travel` 继续承担跨区域道路、境界、物资和金币检查。动画完成后才提交行动并保存；途中停步则以实际中途坐标重新计算已经走过的路段。刷新或关闭页面发生在到达前时，恢复最后一次已保存位置，不扣尚未结算的费用。

桥接层以行走令牌和完整角色/世界/经济/时间/任务修订检查保护动画。一次只有一个行走任务；行走时不能并发交易、休整或启动LLM推演。动画结束后若存档已被恢复、角色已被替换，则丢弃过期结果。保存失败沿用事务回滚机制，角色返回最后有效位置。重新创角主动作废旧行走令牌。

自由交谈仍只填入聊天草稿，由玩家发送后调用模型。LLM提出的跨区行动建议经过玩家授权后，也会进入同一动画入口，不直接瞬移结算。

## 范围

本轮提供三个区域中的道路步行和大陆尺度的路线行走。大陆地图仍是地点/入口网络，不是全大陆每一像素都可行走的无缝地形。尚未制作奔跑、战斗、跳跃、室内穿门、逐栋建筑遮挡、自动战斗或复杂NPC自主行为。通行道路的视觉贴合程度仍可随后续美术精修提高。

使用 `node --test tests/*.test.cjs` 验证规则、状态提交、存档、聊天与移动并发；浏览器另验证透明角色、性别切换、直接寻人、动画进度、附近交互、途中停步、键盘控制和刷新恢复。未调用真实付费LLM。
