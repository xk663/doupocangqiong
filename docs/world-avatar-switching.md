# 地图人物切换

人物与移动形态切换沿用现有外观存档字段，不改变角色身份、资源、位置或游戏时间。

## 加载与替换

- Pixi 场景和轻量 DOM 场景都在后台准备新画面。背景与人物贴图就绪后，才替换当前画面并释放旧人物。
- 每次渲染分配递增版本。连续切换时，只提交最新版本；较早返回的结果和错误均不会覆盖当前人物。
- 离开地图会使未完成的渲染失效，晚到的资源会释放，不再挂载到已销毁的场景。
- 加载失败保留原画面，并提供“重试角色”。重试只重新加载当前外观，不执行地图行动或调用聊天模型。
- 图形上下文丢失后重新构建轻量地图，而不是只创建空容器。

## 贴图缓存

`WorldActor.acquire` 为使用中的贴图分配引用租约，人物销毁后归还。清理只针对没有使用者的资源：保留最近两个闲置人物图集及一个闲置地图背景；当前画面和正在准备的画面受引用保护。

清理同一 URL 的旧资源尚未完成时，新加载会等待清理结束，避免快速切回该人物时，旧的异步卸载破坏新人物使用的纹理。未预加载全部人物或全部形态。

## 验证

`tests/world-avatar-races.test.cjs` 覆盖乱序加载、失败保留、过期错误、地图销毁、卸载期间切回、缓存上限及无游戏副作用的重试。浏览器隔离练习页分别检查 Pixi 与轻量模式的四个人物 × 三种移动形态，以及连续回切。
