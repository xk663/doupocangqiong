# 用户异火设定修改

来源：用户桌面《新建 文本文档 (2).txt》，用户明确要求作为其项目修改。

第18风怒龙炎、第20幽冥毒火、第21阴阳双炎已接入异火榜和默认世界书，共用 assets/js/user-flames.js 中的数据。第16–23名原有错位同时校正，青莲地心火回到19、万兽灵火回到22、玄黄炎回到23，补入第16火云水炎；移除这段榜单中的龙凤焱、六道轮回焱。现有已获得技能和历史记录不重写。

旧默认世界书的三条未改动错误条目按内容和关键词完全匹配迁移，保持ID、启用状态及插入设置。用户编辑过、改名或导入的世界书不覆盖。它们如仍保留旧条目，需要在世界书编辑器自行调整；不会静默添加一个重复且冲突的条目。未启用的世界书不会因此被自动启用。

前端异火卡显示“作者补充设定”，世界书也保留来源。模型可基于火名检索对应条目；不自动在输入“沙漠”时揭示秘密火种坐标。不新增固定地图坐标、掉落概率、免费复活或必杀规则。

本次限定于异火补充和相关榜单错位，不代表默认世界书其他全部条目已完成原著校勘。
