# 驻地第一阶段

驻地读取当前人生的地点与正文时间，按环境展示庭院、客舍、营地或洞府的本地 SVG 交互示意。点选设施会移动场景人物并展示行动条件；点击空地只改变视觉位置，不推进时间。

休整、静修、炼药、研习、邀请与筹备长期居所先生成聊天草稿，保留已有草稿，由玩家发送。预留时长不是实际经过；不因菜单点击增减资源、授予功法或提升实力。

居所登记保存于 `player.residence`，随当前人生、存档与回溯保存。设施与使用权由玩家核对，未登记地点不默认拥有房产或药鼎。

正文可附加 `residence_updates` JSON 元数据，系统只接受能在可见正文中逐字找到依据的记事。新住所建议需要玩家确认，不能直接获得产权。记录与助手回合一并提交，重演沿用原回合快照，避免重复记事。元数据损坏时隐藏控制块并保留正文。

场景没有离线收益、自动 NPC 入住或独立数值结算。本阶段复用主聊天接口，不额外请求模型。

`tests/fixtures/residence.html` 使用合成角色及内存数据库；不访问真实存档、不调用 API。单元测试覆盖事实验证、重演、保存失败、过期编辑和草稿生成。
