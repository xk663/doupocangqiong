# 聊天内核优化说明

日期：2026-10-24。范围：主入口 index.html 与新增 assets/js/tavern-core.js。

## 结构与行为

界面和游戏规则继续由现有原生页面维护。可独立验证的提示词计划、上下文估算、世界书匹配、传输解析、变量操作、角色卡解析及凭据排除移至 tavern-core.js。没有直接复制上游 React 模板，也没有新增前端构建步骤。

请求通过同一生命周期执行，拥有固定会话 ID 和取消控制器。玩家输入先持久化，失败后可“重演天机”复用该输入。成功回复和玩家状态快照写入同一 IndexedDB 事务；取消时不回退到新请求。重演从当前回合的生成前变量与玩家快照重新计算，不累加上一版回复结果。生成期间如果玩家数据被其他界面修改，本次回复拒绝覆盖这些修改。

提示词组装保留配置中的消息角色、有效顺序和深度；空动态标记展开角色及世界书。默认上下文容量 32768、最大回复长度沿用预设，可在预设设置中调整。容量应按实际模型修改。估算不是模型分词器的精确计数；固定内容本身超限时明确报错，不静默裁掉人设。

SSE 和 NDJSON 解析与正文标签解析分开，覆盖跨 UTF-8 字符、跨网络分片、CRLF 和末尾无换行的情况。普通文本也能持续显示。Kobold 使用标准非流式 generate JSON 响应，避免把 JSON 当作正文显示。

世界书检查禁用项、主/次关键词、条目优先级及循环去重，默认递归最多 3 层、注入预算估算 8192 Token。旧版把 selective 当作“不可递归”的条目在启动时迁移到 excludeRecursion，不覆盖其内容。默认世界书仅在库为空时初始化。

## 数据与迁移

v2 手动存档和云备份包含玩家、设置、会话消息与变量、角色卡、预设、世界书、时空、经济、驻地、任务和回溯快照。恢复时上载的同 ID 记录覆盖对应记录，其余本机会话仍保留。API Key、授权令牌和 Webhook 不进入分享数据；恢复仅复用本机相同 ID 且相同 URL 的接口凭据。

自动本地进度使用 doupo_runtime 单条写入保存同一版本的玩家/设置/世界状态，保留旧 doupo_settings、doupo_player、doupo_phase 兼容副本。聊天继续存于现有 IndexedDB。玩家快照时间戳用于选择本地记录与聊天事务中的较新玩家状态。

云备份必须配置用户自己的 Discord Webhook，上传成功并保存新消息编号后才清理上一份。上传失败不删除旧备份。不会验证或使用旧版伪 OAuth 登录状态。历史共享 Webhook 的实际撤销必须由持有人在 Discord 完成。

手动多槽位存档仍受 localStorage 配额限制，大量长会话可能导致保存失败；失败会明确提示，不显示成功。v1 存档缺失的聊天不可凭空恢复。没有快照的历史回复不允许带状态重演，需新回合或已有回溯快照。

## 兼容边界

- OpenAI-compatible Chat Completions、Ollama /api/chat、Kobold /api/v1/generate；不是所有原生提供商协议的适配器，原生 Anthropic Messages 未新增支持。
- 支持项目现有的 ## maintext/option 等正文协议及普通文本。HTML 语义协议仍沿用原项目配置，未实现完整的富文本/战斗卡片运行时。安全的正文默认按文本显示。
- PNG 角色卡支持 chara/ccv3 tEXt 的 Base64 JSON，不宣称支持全部 iTXt/zTXt 格式；未支持的文件明确失败，不伪装成文本导入成功。
- 支持项目内预设数据以及已归一化的常用顺序/注入字段，不宣称完整 SillyTavern 宏、插件、世界书概率/时间触发语义兼容。
- 本轮没有新增次 API 的自动总结调度、向量记忆、服务端代理、云账号体系或全文加密。
- 浏览器直连模型仍需要接口允许当前网页来源的 CORS；Dexie 与字体仍使用原有远程资源。
- game.html、sillytavern.html 是独立历史页面，并未同步主页面的全部功能修订。

## 验证

`node --test tests/tavern-core.test.cjs`：27 项回归，覆盖提示词、世界书、流式边界、请求参数与取消、重演状态、旧请求隔离、角色卡、密钥排除、备份失败顺序、世界书迁移、回溯隔离、原子本地进度与存储配额失败。

浏览器实际检查：首页、设置、新备份表单、预设上下文设置、创建/恢复完整存档，以及无 API 配置下的完整创角与离线开场。测试使用独立本地预览来源的测试角色；没有使用用户真实 API Key，也没有发送 Discord 备份请求。

未执行真实模型服务或 Discord 端到端测试；自动化数据库测试使用内存替身，不能替代全部浏览器事务故障场景。改动尚未推送或部署。
