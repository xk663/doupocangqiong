# 状态一致性与发布准备（2026-10-28）

## 当前状态归属

一份人生存档共用一个当前角色、时间、经济和世界状态。聊天保存叙事消息、记忆、技能待核对记录和战斗过程。`chat.playerState` 是历史副本，不在切换聊天时覆盖实时角色；切换人生使用完整存档。

新人生与新会话记录 `lifeId`。带有不同 `lifeId` 的会话不能直接接着生成或切换为活动会话，需要先读取对应人生存档。旧数据没有足够信息自动辨认历史人生：首次迁移归入当时的当前人生，不猜测旧角色身份，旧完整存档仍可单独读取。

角色实时来源仍是 `GameState.player`；当前进度写入本地 `doupo_runtime`，事务性角色变更同时写入 IndexedDB 的 `tavernSettings.playerState`。启动根据保存时间恢复较新的角色；写入本地进度失败时不提前提高时间戳。`openWorldState` 纳入本地进度及相关数据库事务。

这次没有把所有旧模块改成异步数据库架构：地图继续使用现有同步本地进度事务，角色纠错和战斗使用 IndexedDB。去掉聊天副本的隐式恢复，保证这些路径共享同一当前角色；跨标签页的全面协同编辑不是本次实现的功能。

## 回溯与重演

- 回溯保存和恢复角色、聊天、变量、战斗、时间、经济、地图、任务、驻地运行态，以及记忆表、技能待核对项和开放世界事实。
- 回溯的聊天与角色先在同一数据库事务中落盘；数据库失败时不发布恢复后的状态。
- 数据库内保留对应世界恢复数据。本地备份失败时，刷新仍可从这次数据库恢复点恢复。
- 重演使用原回合之前的记忆、待核对项和世界事实，请求失败不把过去状态提前覆盖到当前内存。
- 旧快照没有保存的记忆和世界事实恢复为空，不能准确补回当时没有保存的数据；不会保留未来事实。

## 战斗规则

浏览器与 Node 明确依赖同一 `BattleRules`。随机数按种子和已使用次数续接，开场敌方行动使用的次数也保存。旧战斗继续保留已存储数值；后续行动使用修正后的随机序列，无法倒推此前错误算法产生的序列。

装备按已装备的 `weapon / armor / accessory / ring` 汇总；每个物品读取 `combatBonuses`，其次 `stats`，最后物品自身的明确数值字段。支持 `hp / qi / attack / defense / speed`。不累加多个别名、不读取背包未装备物品、不根据描述猜数值；只接受有限的非负数字并限制上限。已有聚合装备对象仍兼容。

## 记忆与技能核对

记忆是本地正文摘录，不是模型生成的摘要。保留消息 ID、楼层范围、长消息首尾；历史索引不重复近期摘录范围，确认事实去重。旧记忆保留，重新整理后采用新格式。摘录仍会省略中段，重要事实应单独登记。

记忆编辑通过 `MemoryUI.update` 克隆后提交，提交失败不会污染当前记录。编辑期间阻止发起回合、切换/重置会话、读档以及其他冲突修改。

偏好设置 → 战斗 → 从正文核对已学技能：

1. 扫描当前会话可见正文中的明确玩家习得原句；排除传闻、假设、否定、NPC 与推理块。
2. 名称只取书名号等明确标记或已有法门名称，避免把整句误当技能名。
3. 原句同时明确品阶和战斗效果时，用户确认后按本地规则收录并保留消息来源。
4. 信息不足的记录保存在 `pendingBattleSkills`，在概要的记忆页可核对；不擅自给出品阶或能力。
5. 正文后来提供有效记录后，正常收录流程移除相应待核对项。

## 发布包

```powershell
node --test tests/*.test.cjs
node tools/release.cjs
node tools/release.cjs --build
```

检查命令报告静态引用缺失、发布体积、大文件、外部页面资源和未被 Git 跟踪的运行文件。打包命令只生成本地 `dist/release-*`，不覆盖旧包，不上传、不提交。

发布白名单包括 `index.html`、`map.html` 与应用静态资源，排除测试页面、文档、旧入口、私人配置及用户要求暂留本地的 `assets/images/xiaoyan-xuner`。每个文件记录大小与 SHA-256；复制后再次校验。生成缓存头：脚本和页面重新验证缓存，图片缓存一天。

Git 部署前额外执行 `node tools/release.cjs --require-tracked`。仍有未跟踪运行文件时返回失败，提醒先审核并纳入版本控制；工具不会自动 `git add`。

Dexie 3.2.4 已固定为本地资源并保留许可证，启动不再需要从 CDN 加载数据库库。网页字体仍可外部加载，有系统字体回退。图片原稿未改动，发布包体积不等于首屏下载量；没有新增云端账号、存档后端、QQ 服务或模型代理。
