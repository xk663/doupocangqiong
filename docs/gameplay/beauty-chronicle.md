# 美人榜人物动态

在排行榜 → 美人榜 → 人物动态中填写独立接口类型、地址、Key、模型，保存并开启自动更新。默认关闭。开启后每次主正文生成结束，会附加一次非流式人物档案请求，最多等待25秒，主聊天停止会取消该请求。支持现有OpenAI兼容、Ollama和KoboldCPP传输。

只发送本轮正文（最多末尾24000字符）及各人物最近三条档案作为上下文，不发送主聊天Key。人物API失败不阻止正文保存，旧档案继续保留并显示错误。模型更新需提供能在正文中匹配的连续原句；年龄还需明确岁数，修为需要原句包含该修为。模型归属判断仍有出错可能，未知事实不自动补成小说结局。

日期优先使用正文最后一个scene_checkpoint的data-time，其次ui_sys日期，纯文本仅识别开头日期。支持数字年日、数字或汉字月份；游戏日历每月30日。没有日期沿用前值，不用系统日期或API自拟日期。明确岁数作为当时年龄，此后按相隔360日估算年龄并标注。没有出生日期时不声称精确生日年龄。

人物状态在player.beautyChronicle内，与正文共用数据库事务和回合快照。重演从该轮之前恢复，回溯、导入和新人生分别恢复或清空对应档案。API设置位于本浏览器settings.beautyApi，Key通过既有脱敏器排除在存档导出之外。

本轮仅使用模拟模型测试，没有调用真实付费接口。正文中尚未发生人物事件时显示未知和空记录；不会自动读取原著后期经历填入当前人生。

## 人物自由度

- 管理人物：保留默认人物，允许额外添加30位原创人物；姓名建立后作为档案标识保持稳定，背景可以在纠错中修改。收起仅改变列表显示，不删经历与关系，可以恢复；支持上移下移。
- 关系独立记录信任、亲近、立场、恩怨、承诺，使用描述性文字。人物API仅依据正文证据更新，不凭点击增加好感，不把合作等同恋爱或服从。
- 提取规则要求明确的“普通相识”进入closeness，而不只出现在经历里。模型漏填时，仅对已验证原句中明确指向该人物与玩家的当前关系作字面补全；否定、假设、过去关系、疑问、其他人物关系均不触发此补全，字段锁定始终优先。其他关系不使用关键词猜测。
- 每张卡片支持拜访、传信、邀约、请教、交易、自由行动。操作追加到已有聊天草稿，由用户发送后才调用模型；位置、路程、渠道、资源与人物意愿由实际情景核实。这里没有额外的离屏模拟器，也不把邀请直接执行为地图旅行或交易。
- 纠错可编辑年龄、实力、各项关系，逐字段锁定或解锁。实力锁定阻止人物API覆盖；年龄锁定保护基准岁数，显示仍按正文时间估算增长。纠错是玩家修改世界设定，不声称来源于正文。
- 原创背景、当前档案和锁定约束会进入主聊天实际提示词，并进入独立人物API白名单。隐藏人物仍可参与正文，隐藏不等于在世界消失。
- 修改记录保存前后值、原因和正文日期，最多80条，页面展示最近15条。编辑先写数据库成功再更新页面；推演、移动和人物编辑互斥，过期会话的编辑不提交。人物设置位于player.beautyChronicle，随完整存档、回合快照和回溯保存或恢复，新人生清空。

隔离浏览器验证页面：`tests/fixtures/beauty-social.html`，使用独立测试数据库，测试人物不进入主游戏。验证新增、纠错锁定、邀约草稿、刷新持久化以及收起恢复；模型调用采用自动化模拟。
