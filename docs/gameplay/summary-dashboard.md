# 玩家概要总览

基本信息分栏升级为总览，其余属性、装备、行囊、法门、关系、天赋和经历分栏保留。

## 信息来源

- 当前处境读取当前人生存档和正文时钟，不使用现实时间计时。
- 近期变化比较最近三个完整助手回合的回合前玩家快照。最后一项对比至当前进度，可能包含回合外地图或手动变化，页面明确标注，不声称每项差异都是对应正文的直接结算。
- 目标汇总剧情任务、地图委托与既有任务；自定目标可完成、重新开启，保存到 `player.summaryLedger.goals`。
- 资源读取金币和真实行囊；灵魂、炼药、身体状态缺失时保持未知。
- 人物牵连读取美人榜已记录承诺、恩怨和立场；异火线索保留可信度。
- 历程聚合已有行旅、人物、驻地、异火、玩家历史与纠错记录。能逐字定位当前聊天消息时提供原文跳转；否则注明只有存档记录。总览保留最近80项，页面展示最近25项，其余仍保留在原模块。

## 正文与纠错

主聊天可在正文后输出 `summary_updates`，不新增模型请求。仅接受 realm、soulRealm、alchemyLevel、condition 四个字段。必须有当前可见正文逐字证据、明确玩家字段主语、原文中的连续值；不从NPC实力、猜测、历史状态或思维内容更新玩家。严格校验可能跳过不够明确的表述。数据与助手消息同事务保存，重演使用回合前快照；存储失败不会更新内存。

玩家手动纠错需要原因，记录前值、后值和正文时间。修改的是当前玩家字段，不额外结算资源；原因和自定目标随后续主聊天上下文发送，记录随完整存档和回溯保存。其他模块的信息请通过对应入口核对。新人生清除概要目标、纠错、身体状态与炼药水平，不带入上一人生。

行动建议与自由行动只写入聊天草稿，不自动发送，已有草稿不会被覆盖。所有交互都不调用额外API或生图。`tests/fixtures/summary.html` 使用合成数据和内存数据库验证界面。
